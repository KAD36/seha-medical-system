# بوت تيليجرام لتقارير الإجازة المرضية - منصة صحة

## 🔹 Seha – Sick Leave Bot
**اسم المستخدم على تيليجرام:** @SehaSickLeaves_bot

بوت تيليجرام احترافي لتوليد تقارير الإجازة المرضية بصيغة PDF رسمية معتمدة من وزارة الصحة السعودية.

## ✨ المميزات

- 📄 توليد تقارير PDF بتصميم رسمي دقيق
- 🎨 تصميم يطابق المواصفات الحكومية
- 🔢 توليد تلقائي لرمز الإجازة (PSL)
- 📅 حساب مدة الإجازة بالتاريخين الهجري والميلادي
- 📱 واجهة تفاعلية سهلة الاستخدام
- 🔒 QR Code للتحقق من صحة التقرير
- 🌐 دعم كامل للغتين العربية والإنجليزية

## 📋 متطلبات النظام

- Python 3.11 أو أحدث
- اتصال بالإنترنت
- رمز بوت تيليجرام صالح

## 🚀 التثبيت والتشغيل

### 1. تثبيت Python والمكتبات المطلوبة

```bash
# تثبيت Python (إذا لم يكن مثبتاً)
pkg install python

# إنشاء بيئة افتراضية
python -m venv bot_env

# تفعيل البيئة الافتراضية
source bot_env/bin/activate

# تثبيت المكتبات المطلوبة
pip install -r requirements.txt
```

### 2. إعداد البوت

1. **الحصول على رمز البوت:**
   - تواصل مع @BotFather على تيليجرام
   - أرسل `/newbot`
   - اتبع التعليمات لإنشاء بوت جديد
   - احفظ الرمز المقدم

2. **تحديث ملف الإعدادات:**
   ```python
   # في متغيرات البيئة أو ملف .env المحلي غير المرفوع إلى Git
   BOT_TOKEN='ضع_رمز_البوت_هنا'
   ADMIN_USER_IDS='معرف_المدير_الأول,معرف_المدير_الثاني'
   ```

### 3. تشغيل البوت

```bash
# تفعيل البيئة الافتراضية
source bot_env/bin/activate

# تشغيل البوت
python bot.py
```

## 📱 التشغيل على Termux (Android)

### 1. تثبيت Termux
- حمل Termux من F-Droid أو GitHub
- تجنب النسخة من Google Play Store

### 2. إعداد البيئة
```bash
# تحديث الحزم
pkg update && pkg upgrade

# تثبيت Python و Git
pkg install python git

# استنساخ المشروع أو نقل الملفات
# (انسخ ملفات المشروع إلى مجلد في Termux)

# الانتقال إلى مجلد المشروع
cd /path/to/seha-bot

# إنشاء بيئة افتراضية
python -m venv bot_env

# تفعيل البيئة
source bot_env/bin/activate

# تثبيت المكتبات
pip install -r requirements.txt
```

### 3. التشغيل الدائم 24/7

#### الطريقة الأولى: استخدام screen
```bash
# تثبيت screen
pkg install screen

# إنشاء جلسة جديدة
screen -S seha_bot

# تشغيل البوت
source bot_env/bin/activate && python bot.py

# للخروج من الجلسة مع الحفاظ على التشغيل
# اضغط Ctrl+A ثم D

# للعودة إلى الجلسة
screen -r seha_bot
```

#### الطريقة الثانية: استخدام nohup
```bash
# تشغيل البوت في الخلفية
nohup python bot.py > bot.log 2>&1 &

# لمراقبة السجلات
tail -f bot.log

# لإيقاف البوت
pkill -f bot.py
```

### 4. التشغيل التلقائي عند بدء التشغيل

إنشاء ملف `start_bot.sh`:
```bash
#!/bin/bash
cd /path/to/seha-bot
source bot_env/bin/activate
python bot.py
```

جعل الملف قابل للتنفيذ:
```bash
chmod +x start_bot.sh
```

## 🎯 كيفية الاستخدام

1. **بدء المحادثة:**
   - ابحث عن البوت: @SehaSickLeaves_bot
   - اضغط `/start`

2. **إنشاء تقرير جديد:**
   - اضغط "🆕 إنشاء تقرير جديد"
   - أدخل البيانات المطلوبة خطوة بخطوة

3. **البيانات المطلوبة:**
   - اسم المريض (عربي وإنجليزي)
   - رقم الهوية/الإقامة
   - الجنسية (عربي وإنجليزي)
   - جهة العمل (عربي وإنجليزي)
   - اسم الطبيب المعالج (عربي وإنجليزي)
   - المسمى الوظيفي (عربي وإنجليزي)
   - تواريخ الدخول والخروج (ميلادي وهجري)
   - تاريخ إصدار التقرير
   - اسم المنشأة الصحية (عربي وإنجليزي)
   - الوقت
   - شعار المنشأة (اختياري)

4. **الحصول على التقرير:**
   - راجع البيانات المدخلة
   - اختر "📄 حفظ وإرسال التقرير بصيغة PDF"
   - سيتم إرسال الملف فوراً

## 🔧 استكشاف الأخطاء

### مشاكل شائعة وحلولها:

1. **خطأ في رمز البوت:**
   ```
   telegram.error.InvalidToken: Unauthorized
   ```
   **الحل:** تأكد من صحة رمز البوت في ملف `config.py`

2. **مشاكل الخطوط:**
   ```
   Font is missing glyphs
   ```
   **الحل:** تأكد من وجود ملفات الخطوط في مجلد `fonts/`

3. **مشاكل الصور:**
   ```
   Image file not found
   ```
   **الحل:** تأكد من وجود ملفات الصور في مجلد `upload/`

4. **مشاكل الذاكرة على Termux:**
   **الحل:** أعد تشغيل Termux أو الجهاز

### سجلات الأخطاء:
- راجع ملف `bot.log` للأخطاء التفصيلية
- استخدم `tail -f bot.log` لمراقبة السجلات المباشرة
